# Security policy

This repository is a design case study and does not operate a live public service. It contains
no production credentials, citizen records, municipal data, or exploitable target information.

If you find a secret, personal identifier, or unsafe example, open a private GitHub security
advisory for the repository. Do not place sensitive evidence in a public issue.

The architecture and controls are illustrative. A municipality must complete its own legal,
security, procurement, accessibility, and operational assessments before implementation.
